Discord 外语翻译器

自动翻译 Discord 网页版中的外语消息

基础设置

网络能访问 Google、但官方接口被验证码拦截时，填一个反向代理地址即可；留空则用官方接口。 可用 Cloudflare Worker 转发：fetch('https://translate.googleapis.com' + new URL(req.url).pathname + new URL(req.url).search)

大模型翻译（推荐，质量最好）

兼容 OpenAI 接口的服务均可，例如 DeepSeek（https://api.deepseek.com/v1）、 OpenAI（https://api.openai.com/v1）或自建服务。

更多翻译源（可选，填了自动参与切换）

DeepL 免费 Key 每月 50 万字符；有道智云国内可直连（需在 openapi.youdao.com 申请）； LibreTranslate 适合自建实例。都不填也不影响免费源使用。

测试与维护

使用说明

  • 安装后打开 discord.com 或 web.telegram.org 并刷新页面即可生效；译文会显示在消息下方，点击「译」可收起。
  • 支持 Telegram Web K（/k/）与 Web A（/a/）两套界面。
  • 用鼠标选中消息里的文字，会出现「译」按钮，点一下就能翻译选中的内容（可在上方改为「选中即翻译」）。
  • 回复消息里引用的内容也会单独翻译，显示在引用行下方（Discord）。
  • 链接预览、机器人卡片里的标题和描述也会翻译，显示在卡片下方（Discord）。
  • 「自动」模式会按 浏览器内置 → Google → 腾讯翻译君 → Bing → MyMemory →（已配置的 DeepL/有道/LibreTranslate/大模型）依次切换，一个不可用就自动换下一个。
  • 浏览器内置（离线，免 Key）：使用 Chrome/Edge 自带的端侧翻译，首次点一次页面上的「下载内置翻译包」即可，之后完全离线、无额度限制；网络翻译源全部失效时它也能兜底。
  • 腾讯翻译君不支持俄语等部分语种；这类消息建议使用 Google（需代理）、有道智云或大模型。
  • Google 镜像地址：如果你的网络能访问 Google、但官方接口被验证码拦截，填一个反向代理地址即可（Cloudflare Worker 转发到 translate.googleapis.com）。
  • 消息内容只会发送给所选的翻译服务，扩展不会上传其它数据；缓存仅保存在本地。
